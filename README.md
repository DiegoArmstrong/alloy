# alloy

## What is alloy?

alloy is a Static Site Generator written in Rust. It is made to be used alongisde
Obsidian, to very easily create a simple personal website, containing blog posts,
projects, and more.

## Why build alloy?

### Rust is cool

The first and primary reason is that I have wanted to become fluent with Rust 
for a very long time. I found that a static site generator MVP is a simple enough 
project to at least get started before creating more complex things in the future.

### Simple Website Building

The second reason is that I wanted to build a very simple and personalized 
website where I can easily write blog posts and change the aesthetics quickly. 
I am no web developer, and while I have plenty of respect for the web developers 
of the world, I have no interest in becoming one. I don't want a flashy website 
that requires me to learn how to use N more tools, I just want to write some 
thoughts and publish them on a space that I own on the internet.

### Obsidian is cool

I have used Obsidian for a long time and love it. I figured it would be great
to have the ability to use the same tool that I already love writing technical 
documentation, personal journals, brain dumps, and notes with, for yet another 
writing-related purpose.
